Court Counsel Module

Version 2.0 - DNN 9.11 Module for managing court counsel case tracking and reporting.

Overview

The Court Counsel module provides case management capabilities including search, data entry, reporting, and administrative functions for court counsel operations.

Module Views

ViewDescription
SearchSearch for cases by case name, case number, or attorney.
Data Entry (EditHistory)Create and edit case history records.
ReportsGenerate statistical reports filtered by date range, status, attorney, county, and requestor.
Data SheetFull data sheet view with filtering and export capabilities (Excel, CSV, PDF).
AdminAdministrative CRUD for lookup tables: Case Types, Attorneys, Counties, Phases, Requestors, Actions, and Time Spent.
Update Case NameBulk update party names for a given case number.
SettingsModule settings for admin role and template configuration.

Settings

SettingDescription
Admin RoleThe DNN role that grants administrative access to the module (Admin tab visibility).
TemplateDefault template text used when creating new entries.

Requirements

  • DNN Platform 9.11 or later
  • .NET Framework 4.7.2 or later
  • Bootstrap 4 (included with DNN)
  • jQuery DataTables with Buttons extension
  • Font Awesome 5

Installation

Install the module through the DNN Host Extensions page using the module package (.zip) file.

Note: After installation, configure the Admin Role in the module settings to enable administrative features.
