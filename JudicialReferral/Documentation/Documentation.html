Judicial Referral Module

This module routes judicial referrals (motions) from Judicial Assistants to Judges and, optionally, to Court Counsel for research/assistance.

Roles

  • Judge - reviews a JA-submitted referral, selects motion type, and accepts or declines Court Counsel assistance.
  • Ja (Judicial Assistant) - creates new referrals with attachments and submits them to the Judge.
  • Court Counsel - receives referrals accepted by a Judge and copies them into the Court Counsel log.

Workflow

  1. JA creates a new referral (Referral view) with Judge, case info, motion title, motion date, and attachments.
  2. Judge is emailed and opens the referral via the Review view to classify the motion (Criminal/Civil/Family/Appeals) and respond.
  3. If the Judge seeks Court Counsel assistance, the referral is emailed to Court Counsel.
  4. Court Counsel opens the referral via EditLogEntry to copy the case details into the CourtCounsel history log.
  5. At any point, Court Counsel can mark the referral complete from the search list.

Data Storage

Data is stored using DNN DAL2 (PetaPoco) in the following tables:

  • tjc_jr_referrals - one row per judicial referral
  • tjc_jr_attachments - one row per uploaded attachment

EditLogEntry also reads dropdown values from and writes new rows to the CourtCounsel tables (tjc_cc_*).
